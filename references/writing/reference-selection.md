# Reference Selection

Use this reference when selecting bibliography entries for a Chinese undergraduate thesis.

## Priority

School template, task book, advisor requirements, and department notices override all defaults here.

## School Requirements (江西软件职业技术大学)

根据学校写作规范：

- 参考文献著录格式要符合国家标准 GB/T 7714-2015
- 建议在学校图书馆的中国知网电子资源平台中直接导出 GB/T 7714-2015 格式引文
- 文献中出现的 DOI，全称为 Digital Object Unique Identifier，是指数字对象唯一标识符。有的文献没有 DOI。在毕业论文末尾列出参考文献时，可以删除 DOI 及后面所有内容，也可以保留
- 不少于 20 篇，其中至少 5 篇外文文献
- 近五年文献原则上不少于总参考文献的 60%
- 不允许使用网址作为文献来源

## Default Heuristics

When no school-specific requirement exists:

- Prefer recent, verifiable sources, but do not discard authoritative older sources solely by year.
- Keep the Chinese/English ratio aligned with the thesis topic and available verified literature.
- Treat total count as a target from the school or advisor, not a fixed number.
- Prefer sources with DOI, publisher pages, journal pages, university database records, or other stable verification paths.

## Hard Rules

- Do not fabricate references.
- Do not use a source when title, authors, year, venue, or URL/DOI cannot be verified.
- Mark uncertain candidates as `needs_check` instead of citing them as confirmed.
- Generate or update the reference verification checklist before final delivery.

## Citation Format Rules

### Single Citation Only
- Each reference may only be cited once in the entire thesis.
- No multiple citations allowed in one location (e.g., `[1-3]` or `[1][2]` is prohibited).
- The citation number must be a single number in square brackets: `[1]`, `[2]`, `[3]`, etc.

### Sequential Numbering
- References must be numbered sequentially from `[1]` through `[n]` without gaps.
- The numbering order follows the first appearance of the citation in the body text.
- Example: if `[3]` is cited before `[2]` in the body, the reference list should still be `[1][2][3]` with `[2]` being referenced at its first appearance location.

### Format Standard
- Citation format: `[n]` (square brackets with number)
- Position: right superscript (右上标)
- No parentheses, no multiple numbers

# 中文论文表达对照表

## 概述

本表按功能分类收录常用学术表达，供 AI 写作时直接取用。遵循"推荐表达"，避免"避免表达"。

---

## 一、引出目的与问题

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 提出研究背景 | 随着……的发展，……日益成为……的研究热点 | 随着社会的发展，……越来越重要 |
| 指出问题 | 然而，现有……存在……问题，主要体现在…… | 但是现在有很多问题 |
| 引出目的 | 为解决……问题，本文提出…… | 为了解决这个问题 |
| 说明意义 | 本研究对于……具有重要的理论/实践意义 | 这个研究很有意义 |
| 提出目标 | 本文旨在……，具体目标包括…… | 本文的目标是…… |

**示例：**
```
✅ 为解决社区服务中时间记录不透明、信任成本高的问题，本文提出了一种基于区块链的时间银行社区服务平台。

❌ 为了解决社区服务中的问题，本文做了一个基于区块链的平台。
```

## 二、描述方法与设计

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 提出方法 | 本文提出/设计/构建了一种……方法/系统/模型 | 本文做了一个…… |
| 说明架构 | 系统采用……架构，主要包括……模块 | 系统有……部分 |
| 描述流程 | 该流程分为……阶段，具体步骤如下…… | 流程是这样的 |
| 引出设计 | 本章从……角度出发，分别就……展开设计 | 本章讲一下……的设计 |
| 说明选择 | 选择……方案，主要基于以下考虑…… | 选了……是因为…… |

**示例：**
```
✅ 本章从系统架构、功能模块、数据库设计三个角度出发，分别就平台的整体架构、核心功能和数据存储展开详细设计。

✅ 系统采用前后端分离架构，前端基于 Vue.js 框架，后端基于 Spring Boot 框架，数据库使用 MySQL。

❌ 本章讲一下系统怎么设计的。
```

## 三、描述实验与结果

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 引出实验 | 为验证……，本文设计了……实验 | 做了个实验 |
| 描述数据 | 实验数据如表X所示，…… | 实验数据是…… |
| 说明结果 | 实验结果表明/显示/证明…… | 实验发现…… |
| 引用图表 | 如图X所示，…… / 由表X可知，…… | 看图/看表 |
| 量化结果 | ……提升了X%，……降低了Y% | ……提升了很多 |
| 对比分析 | 与……相比，本文方法在……方面提升了X% | 比……好 |

**示例：**
```
✅ 实验结果如表 3-1 所示，在 1000 并发用户的测试场景下，系统平均响应时间为 0.8 秒，峰值响应时间为 1.2 秒。

✅ 如图 4-2 所示，随着并发用户数的增加，系统响应时间呈线性增长，但始终保持在 2 秒以内。

❌ 做了实验发现系统性能还不错。
```

## 四、分析与讨论

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 解释原因 | 这一结果主要源于…… | 这是因为…… |
| 分析影响 | ……对……产生了显著影响，具体表现为…… | ……影响了…… |
| 指出发现 | 值得注意的是，…… | 有个发现 |
| 说明规律 | 从……可以看出，……呈现出……的趋势 | ……有规律 |
| 总结特点 | 该方法具有……特点，主要体现在…… | 这个方法有……特点 |

**示例：**
```
✅ 这一结果主要源于系统的缓存机制有效降低了数据库查询次数。值得注意的是，在高并发场景下，缓存命中率仍保持在 85% 以上。

✅ 从图 5-3 可以看出，随着节点数量的增加，系统的吞吐量呈现出先上升后趋于平稳的趋势。

❌ 这是因为有缓存。发现系统有规律。
```

## 五、说明局限与不足

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 承认局限 | 受限于……，本文未能覆盖…… | 由于时间有限 |
| 说明不足 | 本研究存在以下不足：（1）……；（2）…… | 有一些不足 |
| 指出范围 | 本文的研究范围限定在…… | 只研究了…… |
| 提出展望 | 未来工作将从以下方面展开：…… | 以后再改 |

**示例：**
```
✅ 受限于实验条件和时间，本文未能对系统在极端负载下的表现进行充分测试。未来工作将从性能优化、安全加固、功能扩展三个方面展开。

✅ 本研究存在以下不足：（1）实验场景相对单一，未覆盖所有用户类型；（2）系统安全性分析不够深入。

❌ 由于时间有限，有些地方没做好。
```

## 六、总结贡献

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 总结工作 | 本文的主要贡献如下：（1）……；（2）……；（3）…… | 本文做了很多工作 |
| 强调创新 | 本文的创新点在于…… | 本文的创新是…… |
| 概括成果 | 本文实现了……，达到了……目标 | 本文实现了…… |
| 回顾全文 | 本文围绕……问题，从……展开研究，最终实现了…… | 本文研究了…… |

**示例：**
```
✅ 本文的主要贡献如下：（1）提出了基于区块链的时间银行社区服务架构；（2）设计了智能合约驱动的时间币发放机制；（3）实现了去中心化的社区服务交易平台。

✅ 本文围绕社区互助养老中的信任缺失问题，从技术架构、业务流程、数据安全三个维度展开研究，最终实现了基于区块链的时间银行社区服务平台。

❌ 本文做了很多工作，实现了很多功能。
```

## 七、过渡与衔接

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 章节过渡 | 在完成……的基础上，本章进一步…… | 接下来讲…… |
| 段落过渡 | 基于上述分析，…… | 所以…… |
| 补充说明 | 此外/另外/同时，…… | 还有…… |
| 转折对比 | 然而/但是/尽管如此，…… | 但是…… |
| 举例说明 | 以……为例，…… | 比如…… |
| 总结归纳 | 综上所述/总而言之，…… | 总的来说…… |

**示例：**
```
✅ 在完成系统架构设计的基础上，本章进一步就数据库设计、接口设计和安全机制展开详细论述。

✅ 基于上述需求分析，本文确定了系统的核心功能模块。此外，考虑到系统的可扩展性，预留了第三方接口。

❌ 接下来讲数据库设计。
```

| 功能 | 推荐表达 | 避免表达 |
|------|----------|----------|
| 引用文献 | 文献[X]指出/认为/提出…… | 有研究说…… |

## 使用说明

1. **直接取用**：AI 写作时可直接从本表中选取合适的表达
2. **灵活调整**：根据具体语境适当调整句式，但保持学术规范
3. **避免生搬硬套**：表达应自然流畅，避免机械套用
4. **结合禁用词表**：参考 `prose-style-guide.md` 中的禁用词表，避免空泛表达
